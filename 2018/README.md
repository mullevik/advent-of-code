# Advent of Code 2018

Solutions to https://adventofcode.com/2018/

Just a pure programming practice with Zed editor and simple python code.

## Usage

Evaluate all days (assuming you have real inputs in `inputs/` directory in the format of `day.in` (e.g. `inputs/01.in`))

```
uv run eval
```

Evaluate some days

```
uv run eval 1 3
```

Run unit tests

```
uv run pytest
```
